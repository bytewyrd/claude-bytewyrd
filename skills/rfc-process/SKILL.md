# RFC process

The full process is in [references/rfc-process.md](references/rfc-process.md). Read it before you write, review, approve or implement an RFC, and treat it as the source of truth for RFC work.

It applies to a repository that has a `docs/rfcs/` directory at its root. Any project extensions to it are in that repository's `AGENTS.md`.
